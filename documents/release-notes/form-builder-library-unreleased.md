# Form Builder Library Upcoming Release

Find forms and images visually, organize form components into nested folders, and use tags to find related forms across your library.

These changes are prepared for an upcoming release and are not assigned a package version yet.

## Choose images from a visual library

Image sections open a **Select Image** window with thumbnails, nested folders, and search by label, description, or API name. Select an image to apply it, then use **Change Image** to choose another. The selected image fills the editor's available width, with **Image Override Field** below it.

![Choosing and changing an Image section asset from the image library](../.gitbook/assets/873-image-section-selector-demo.gif)

See [Choosing an image for a section](../screen-components/form-builder.md#choose-an-image-for-a-section).

## Tag reusable forms

Add existing or new tags under **Settings → Folder and Tags**. Tags appear as removable pills and become filters in the form selector.

![Adding Address and Mailing tags to a form](../.gitbook/assets/874-form-tags-demo.gif)

## Organize forms in nested folders

Choose a folder or create a subfolder in the **Select Folder** window, then save the form. The example files an address form under **Grants → Compliance → Address Blocks**.

![Creating and selecting a nested folder for a form](../.gitbook/assets/874-form-folder-create-demo.gif)

## Browse form previews by folder

The **Select Form Component** window shows form previews beside a folder tree. Select a folder to narrow the cards, review a card's description and tags, and select it to open the form in Form Builder.

![Finding the Address form through the nested folder tree](../.gitbook/assets/874-form-browser-folders-demo.gif)

## Find forms by tag

Filter previews by tags such as **Mailing** or **People**, alongside the existing category filter and name or description search.

![Filtering form previews by tags and selecting Alternate Contact](../.gitbook/assets/874-form-browser-tags-demo.gif)

See [Organize Form Components](../how-to-guides/organize-form-components.md) for the complete workflow.
